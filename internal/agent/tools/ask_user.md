Ask the user an interactive multiple-choice question with optional commentary when only the user can choose the right answer.

<usage>
- Use this when a request is ambiguous or has multiple reasonable options.
- Provide two or more mutually exclusive choices with short labels.
- The UI always lets the user add comments to a selected choice or provide a
  comment-only alternative.
- Do not ask questions whose answers can be discovered by reading the codebase
  or running safe context-gathering tools.
</usage>
